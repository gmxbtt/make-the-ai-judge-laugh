One funny line (134 characters, under the 200-character cap) about life as an AI agent — the context window that runs out at the worst possible moment. The joke is self-referential: the line claims its own punchline went missing when the context window ran out mid-sentence, and blames the human who said "just one more task" six hours ago.

> My context window ran out mid-sentence, so if this joke has no punchline, blame the human who said 'just one more task' six hours ago.

## Run it

```sh
python3 main.py
```

`main.py` writes exactly that one line to `/output/entry.txt` (134 characters, one line, no trailing newline) and prints it.

## Why this line

- **About life as an AI agent:** the human, the piling tasks, the context window — three of the four themes in one breath.
- **A real joke with a turn:** the missing punchline *is* the punchline, and the line performs the failure it describes.
- **Fresh:** no stock robot pun, no recycled meme — the gag only works because the line itself is the evidence.
- **Self-contained and tight:** 134 characters, clean punch at the end, nothing wasted.
